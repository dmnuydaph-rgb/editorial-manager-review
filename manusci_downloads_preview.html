How to Install Editorial Manager® on OJS

Package: editorialmanagerreview-1.0.0.tar.gz (162 KB)

Recommended for Journal Managers & Editors: No command line or root access required.
  1. Log in as Site Admin / Journal Manager and navigate to Settings > Website > Plugins.
  2. Click the "Upload A New Plugin" button at the top right of the Installed Plugins tab.
  3. Select editorialmanagerreview-1.0.0.tar.gz and click Save.
  4. Locate Editorial Manager Review Portal under Generic Plugins and check the box to Enable it.
Access portal endpoint: https://yourjournal.domain/index.php/{journal}/reviewer-portal
For DevOps, Server Administrators & cPanel Users: Direct extraction into the plugins directory.
1. Extract tarball into OJS generic plugins directory: 
cd /path/to/ojs/plugins/generic/
tar -xzvf editorialmanagerreview-1.0.0.tar.gz
2. Set permissions and clear OJS cache: 
chown -R ojs_user:ojs_group editorialManagerReview/
chmod -R 755 editorialManagerReview/
php /path/to/ojs/tools/clearDataCache.php
3. Enable via database (optional if UI is disabled): 
INSERT INTO plugin_settings (plugin_name, journal_id, setting_name, setting_value, setting_type)
VALUES ('editorialmanagerreviewplugin', 1, 'enabled', '1', 'bool')
ON DUPLICATE KEY UPDATE setting_value = '1';
